### WPFluent - WordPress Plugin development made easy.

### Installations

- `npm install`
- For Dev: `npx mix watch`
- For Production: `npx mix --production`

### for Frontend Development

- For Dev: `npx mix --mix-config=public-webpack.mix.js watch`
- For Production: `npx mix --mix-config=public-webpack.mix.js --production`
